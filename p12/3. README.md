# FIFO Memory using Verilog

## 📌 Project Overview

This project implements a **FIFO (First-In First-Out) Memory** using Verilog HDL.

FIFO memory stores data in such a way that the **first data written into the memory is the first data read out**.

This project includes:

* Verilog RTL code
* Verilog testbench
* Simulation waveform
* FIFO status signals
* Project documentation

## 🎯 Objectives

* Design a FIFO memory using Verilog HDL.
* Understand FIFO read and write operations.
* Implement `full` and `empty` status flags.
* Verify the design using a testbench.
* Observe the design behavior using simulation waveforms.

## ⚙️ Specifications

| Parameter    | Value        |
| ------------ | ------------ |
| Data Width   | 8 bits       |
| FIFO Depth   | 16 locations |
| Clock        | 10 ns        |
| Reset        | Active High  |
| Write Enable | `wr_en`      |
| Read Enable  | `rd_en`      |

## 🔌 Inputs and Outputs

### Inputs

* `clk` – Clock signal
* `reset` – Reset signal
* `wr_en` – Write enable
* `rd_en` – Read enable
* `data_in` – Input data

### Outputs

* `data_out` – Output data
* `full` – Indicates FIFO is full
* `empty` – Indicates FIFO is empty

## 🔄 FIFO Operation

### Write Operation

When:

```text
wr_en = 1
empty/full condition allows writing
```

the input data is stored in the FIFO.

### Read Operation

When:

```text
rd_en = 1
FIFO is not empty
```

the oldest stored data is read from the FIFO.

### FIFO Principle

```text
Data A → Data B → Data C → Data D
   ↓
First In → First Out
   ↓
Data A → Data B → Data C → Data D
```

## 🧪 Testbench

The testbench performs the following operations:

1. Applies reset.
2. Writes four 8-bit values into the FIFO.
3. Stops the write operation.
4. Reads the stored values.
5. Monitors `data_in`, `data_out`, `full`, and `empty`.
6. Generates a waveform file for simulation.

Test data:

```text
A1
B2
C3
D4
```

Expected read sequence:

```text
A1 → B2 → C3 → D4
```

## 📊 Expected Result

The FIFO should produce the output in the same order in which the data was written.

```text
Write:  A1 → B2 → C3 → D4

Read:   A1 → B2 → C3 → D4
```

Therefore, the FIFO follows the **First-In First-Out** principle.

## 🖥️ Simulation

The design can be simulated using tools such as:

* Icarus Verilog
* GTKWave
* ModelSim
* Vivado

For Icarus Verilog:

```bash
iverilog -o fifo_sim src/fifo_memory.v testbench/fifo_memory_tb.v
```

Run the simulation:

```bash
vvp fifo_sim
```

Open the waveform:

```bash
gtkwave waveform.vcd
```
